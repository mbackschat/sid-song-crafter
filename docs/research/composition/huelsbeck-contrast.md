## Machine initialization contract

The selected RSID init at `$CC86` must receive `A=2` (one-based subtune 3), enter through a real `JSR`, and return to an idle host. Source inspection shows that this path copies `$71E3–$8FFF` to `$41C0–$5FDC`, calls the relocated initializer `$41C9` with internal `A=1`, installs `$CCF1` as the IRQ handler through `$0314/$0315`, enables raster interrupts and returns. That handler calls `$41C0`, acknowledges the VIC interrupt and exits through the KERNAL. The init/play addresses in the file are therefore not a callable once-per-refresh player contract.

Initialize bank `$37` and explicitly retain the renderer's raster-high-bit setup. The pinned libsidplayfp 3.1.1 [`src/psiddrv.a65`](https://github.com/libsidplayfp/libsidplayfp/blob/v3.1.1/src/psiddrv.a65) sets `$D011=$9B` for this RSID path. Giana changes `$D012` to zero without clearing that high bit, selecting raster line 256; ordinary KERNAL READY state would instead leave line 0. A VICE probe must declare this setup before comparing cadence. This source inspection establishes the entry contract, not equivalence between the renderer's complete initial machine state and a KERNAL-started probe, exact PCM identity or a completed runtime capture.
