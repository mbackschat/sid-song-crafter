[The listening catalogue](listening-catalogue.md) supplies concrete works, versions, credits, and study questions. [Study corpus and rights](study-corpus.md) explains HVSC, STIL, editable examples, and provenance. The paired studies cite interviews, manuals, published analysis, and implementation evidence; they distinguish documented facts from proposed listening or reconstruction exercises.

For each new study, record the exact work/platform/version, collaborators, source links, editor and driver, concrete sound mechanisms, reusable lessons, and unresolved questions. File inspection is not a listening session, and a modern remix is not evidence of what the original SID program did.
