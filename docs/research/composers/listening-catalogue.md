# SID listening and inspection catalogue

Checked on 2026-10-12. This is a starting corpus for the [composer studies](README.md), with focused questions that can be answered by listening, soloing voices, and inspecting writes. Reference listening and register tracing have not been performed for this catalogue. Credits, targets, and file identities come from the linked studies, archive records, inspected headers, or the composer's own release page; an unanswered question is not a claim about an instrument's implementation.

Start with *Cybernoid II* for a documented programmable instrument engine, *Shades* and its corrected variant for filter intent, and *A Mind Is Born* for a modern 8580-specific composition with an annotated implementation. Together they connect the historical drivers, model differences, and expressive native authoring without requiring a large download first.

Evidence labels: **H** = SID header inspected in the paired study; **A** = archive metadata; **P** = first-hand composer/release account; **I** = implementation inspected, including explicitly identified reconstructions; **S** = published analysis. These labels establish the stated evidence, not a ranking of musical quality. No row has completed listening/trace evidence. “Unknown” means this catalogue has no checked target declaration; it does not authorize choosing a model arbitrarily.

## Record a useful comparison

For each actual session, retain the downloaded file and SHA-256, selected one-based subtune or musicdisk piece, player/emulator revision, PAL/NTSC clock, SID model(s), filter/digi settings, and captured time range. Record whether the evidence is a header, source inspection, observed writes, modeled audio, or physical hardware. Use the named study question to produce one finding, with the responsible register trajectory or musical passage, instead of adding an unsupported adjective to the catalogue.

Compare short phrases at equal listening level, then return to the full mix. Soloing a voice can expose its trajectory, but sync/ring modulation and the shared filter may depend on other voices; muting them can change the instrument being studied. A reconstruction or modern instrument experiment should retain its own source and settings, separately from the historical reference.

The catalogue links to reference material rather than incorporating recordings or historical sound-data tables. [Study corpus and rights](study-corpus.md) explains archive provenance. Åkesson's release pages state their individual licenses: *A Mind Is Born* is BY-NC-SA, while *Machine Yearning* is CC BY-NC 4.0; use the linked original declarations for any redistribution decision. Archive availability and a player repository's code license do not by themselves license every composition or recording.
