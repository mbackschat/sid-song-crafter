## Musical brief

The user requires enough independent instrumental roles for dual SID to make a useful musical difference, while the same piece must also sound good on a single SID. Avoid a piano-only duet and avoid excessive orchestration. The dual listening matrix is native chip A left and chip B right: `L=A`, `R=B`, with no per-channel normalization. Melody and bass have matching programs on both sides; second violin is left and viola right. A diagnostic fold-down uses `(A+B)/2`; it is not the separately authored single-SID version. Stereo adds one distinct source part, while the other two extra voices center melody and bass. The single-SID selection prioritizes viola in the Minuet because the second violin often doubles the melody an octave lower; the Trio uses the second violin's alternating accompaniment. This avoids sacrificing essential harmonic information merely to keep one fixed track assignment.

Their acceptance belongs to this complete ensemble; it does not establish universal solo-patch suitability or orchestral realism.

The MIDI encodes approximately quarter = 112.00006. The selected performance uses quarter = **110.87463199598375**, about **1.005% slower**, retaining every selected note's pitch, onset and duration in beat units. At PAL this is 27.125 frames per quarter; an eight-beat pattern spans 217 frames. This deliberate tempo choice makes repeated source phrases share native patterns: the unchanged stereo score fits in 59 PAL and 97 NTSC patterns, within the 105-pattern limit. The original six-beat packing at quarter = 112 required 167 PAL stereo patterns. Other tested PAL packing boundaries at that tempo also failed. No generic compiler limit was weakened and no source phrase was removed. This is a listening-accepted, case-specific performance compromise, not automatic permission to retime future scores.

The selected 264-beat performance lasts about 142.86 seconds before its release/verification tail. Full WAVs last about 146.38 seconds. Ending comparisons extend through 146 seconds, covering the final phrase, native stop and settled tail. The plain reference uses the same reduced score and timing with triangle instruments; it is a generated control, not an orchestral recording.
